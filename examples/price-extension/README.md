# Калькулятор цены: от поиска BSL до файла расширения

В расширении `Учебное` есть обработка «Расчет цены». Пользователь вводит цену и количество, нажимает **Рассчитать**, а форма показывает сумму. Задача урока — найти формулу и добавить рядом с ней пояснение об округлении. Правку сделаем в исходниках расширения и соберём их в `.cfe`.

`v8project.yaml` объявляет два соседних набора: `main` (`src/`) — минимальная родительская конфигурация с русским языком, `tutorial` (`ext/`) — расширение с обработкой, модулем объекта и управляемой формой. **Рабочий каталог сессии — каталог с этим `v8project.yaml`.**

## Быстрая проверка из исходников порта

Из корня репозитория, с Node.js 24+:

```sh
node examples/verify-price-extension.mjs          # поиск, diff, применение токена и валидация
node examples/verify-price-extension.mjs --build  # дополнительно: план сборки и настоящий .cfe
```

Первой команде нужно только ядро Unica. Второй — движок `v8-runner` и установленная платформа 1С:Предприятие с `ibcmd` (проект в режиме совместимости 8.3.27). При первом запуске нужен доступ к GitHub для загрузки рантайма в кэш. Для `--build` лаунчер заранее загружает движки. Подключение к своей базе не требуется: сборщик создаёт временную базу в рабочей копии. Установка расширения в базу в этот урок не входит.

Обе команды начинают с чистой временной копии. При успехе первая удаляет её, а `--build` оставляет копию и печатает абсолютный путь к `.cfe`. При ошибке копия остаётся для диагностики. Когда она больше не нужна, можно удалить весь напечатанный каталог.

## Те же шаги в DSH

Скопируйте `v8project.yaml`, `src/` и `ext/` вместе в новый пустой каталог. Откройте его в новой сессии с [установленным пресетом «Unica 1C»](../../README.md#установка). Ниже `unica.*` — краткие имена инструментов. JSON по ссылкам — точные аргументы для вызова: их же читает проверочный скрипт. На `unica.view {}` должны быть видны `main` и `tutorial` с типами `configuration` и `extension`.

### 1. Найти формулу и место вызова

Вызовите `unica.search` с [search.json](requests/search.json). Ожидайте `totals.matches: 2`, `totals.files: 2`:

| Где | Что должно найтись |
|---|---|
| [Модуль объекта](ext/DataProcessors/Учебное_РасчетЦены/Ext/ObjectModule.bsl), строка 2 | Объявление `Функция РассчитатьСумму(Цена, Количество) Экспорт` |
| [Модуль формы](ext/DataProcessors/Учебное_РасчетЦены/Forms/Форма/Ext/Form/Module.bsl), строка 9 | Вызов `Обработка.РассчитатьСумму(ЦенаРасчета, КоличествоРасчета)` |

Чтобы прочитать формулу, вызовите `unica.view` с `{"at":"tutorial:DataProcessor.Учебное_РасчетЦены.Module.Object.Method.РассчитатьСумму.Body"}`. У функции одна строка расчёта: `Возврат Окр(Цена * Количество, 2);`. Например, для цены `12,35` и количества `1,5` ожидаемая сумма — `18,53`. Отрицательные значения отклоняются.

### 2. Добавить пояснение на форму

1. Вызовите `unica.apply` с [edit-form.json](requests/edit-form.json). Ожидайте `data.mode: "preview"` и непустой `data.executionToken`. На диске [Form.xml](ext/DataProcessors/Учебное_РасчетЦены/Forms/Форма/Ext/Form.xml) всё ещё без элемента `ПодсказкаРасчета`.
2. Подставьте **полученный в этой копии** токен в `unica.diff {"executionToken":"<токен>"}`. В `data.chunks` должен быть только `DataProcessors/Учебное_РасчетЦены/Forms/Форма/Ext/Form.xml`. В части `after` видна новая `LabelDecoration` с текстом «Сумма = цена × количество, округление до 2 знаков».
3. Если это нужная правка, вызовите `unica.apply {"executionToken":"<токен>"}` — без `at` и `ops`. Ожидайте `data.mode: "published"`. Теперь надпись есть на диске; её можно прочитать по адресу `tutorial:DataProcessor.Учебное_РасчетЦены.Form.Форма.Item.ПодсказкаРасчета` через `unica.view`.
4. Вызовите `unica.check` по очереди с `{"at":"tutorial:DataProcessor.Учебное_РасчетЦены.Form.Форма"}` и `{"at":"tutorial:Configuration"}`. В обоих ответах ожидайте `data.status: "passed"`, валидаторы `form` и `cfe` соответственно.

### 3. Собрать изменённое расширение

1. Вызовите `unica.run` с [make.json](requests/make.json). В нём `extension: "tutorial"` — имя набора из `v8project.yaml`. Ожидайте `dryRun: true`, `plan.artifact.kind: "cfe"`, `providerDispatched: false`. В чистой копии файла `build/out/Учебное.cfe` ещё нет. Для этого шага требуется `v8-runner`.
2. Повторите `unica.run` с теми же `op` и `args`, заменив `dryRun` на `false`. Если в ответе любого из этих вызовов есть `data.task.taskId`, дождитесь именно этого задания через `unica.task.result {"taskId":"<id>","waitMs":5000}`. Пока ответ содержит `data.task`, запрашивайте результат с тем же ID. Для ожидания не запускайте `make` повторно.
3. Успех — это `providerDispatched: true`, `artifact.kind: "cfe"` и **непустой файл** `build/out/Учебное.cfe`. Сверьте его размер и SHA-256 с `data.artifact.size` и `data.artifact.sha256`. На macOS/Linux это можно сделать командой `shasum -a 256 build/out/Учебное.cfe`, в PowerShell — `Get-FileHash -Algorithm SHA256 build/out/Учебное.cfe`. Скрипт `--build` делает обе сверки автоматически; фиксированного хеша для всех сборок нет.

Если формы или набора нет в ответе — сверьте `workspaceRoot` у `unica.view {}` с путём к копии. Если план сборки прошёл, а сборка упала — прочтите диагностику `task.result` и проверьте, доступен ли `ibcmd` нужной версии. Для ручного запуска путь можно задать в `v8project.local.yaml` рядом с проектом ([формат настройки](../../dsh-unica-plugin/references/tooling/v8project.md#strict-platform-resolution)). Чтобы повторить весь урок, возьмите новую копию исходников: имя добавленного элемента уже занято в пройденной.
