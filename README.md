# unica for DeepSeek Harness

Порт публичного плагина [Unica](https://github.com/IngvarConsulting/unica) —
инструментария разработки на 1С:Предприятии для Codex и Claude Code — на
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

Апстрим не содержит кода под DSH, поэтому это интеграционный слой: 76 навыков
1С и MCP-сервер `unica` с 74 инструментами подаются DSH как его собственные
навыки и инструменты.

## Что внутри

```
dsh-unica-plugin/
  skills/            76 навыков 1С (skills/unica-<name>/SKILL.md)
  references/        48 справочных документов, на которые ссылаются навыки
  bootstrap/         нативные лаунчеры unica: darwin-arm64, linux-x64, win-x64
  tools/             сопровождение: генератор навыков и проверки целостности
  install.mjs        установка в $DSH_HOME (агент-пресет и/или патч профиля)
  package.mjs        сборка архива для переноса
  cordis.patch.yml   шаблон патча профиля
  tool-map.json      карта 74 инструментов: unica.* -> mcp__unica__*
```

Подробности — в [`dsh-unica-plugin/README.md`](dsh-unica-plugin/README.md).

## Быстрый старт

```sh
cd dsh-unica-plugin
node install.mjs --target both
```

Затем начать новую сессию DSH и выбрать пресет **«Unica 1C»**. Состав сессии
фиксируется при создании, поэтому в уже идущей сессии пресет не сменится.

Требуется Node.js; для операций, реально запускающих платформу, —
1С:Предприятие. Первый запуск скачивает ядро unica (~100 МБ) с GitHub.

## Принципы порта

- **Код апстрима не изменяется.** Переписывается ровно одно: пространство имён
  инструментов, потому что DSH отдаёт MCP-инструменты как
  `mcp__<server>__<name>` и не допускает точку в имени функции.
- **Абсолютные пути не хранятся в репозитории.** Их подставляет `install.mjs`
  при установке, поэтому копия работает на другой машине и под другой ОС.
- **Способ запуска выбирается по платформе.** Windows — прямой
  `unica-bootstrap.exe`; macOS и Linux — `sh bootstrap/launch.sh`, где
  апстрим сам разбирает ОС и архитектуру.

## Проверки

```sh
cd dsh-unica-plugin
node tools/check-refs.mjs .                                  # 61 ссылка на справочники
node tools/check-encoding.mjs skills references              # кодировка портированных файлов
```

Обе проверки — не формальность: первая ловит рассогласование навыков и
справочного корпуса, вторая — порчу UTF-8 при копировании (навыки почти
сплошь русскоязычные).

## Лицензии

Собственный код Unica — **LGPL-3.0-or-later**. Поставляемые бинарники
сохраняют свои лицензии, включая **AGPL-3.0-only** для `v8-runner`; полный
разбор — в [`dsh-unica-plugin/ATTRIBUTIONS.md`](dsh-unica-plugin/ATTRIBUTIONS.md).

Порт вызывает эти бинарники отдельными процессами и не линкует их, поэтому
лицензионная цепочка апстрима не меняется. При распространении сборки
учитывайте, что `bootstrap/` — это прекомпилированные бинарники апстрима.
